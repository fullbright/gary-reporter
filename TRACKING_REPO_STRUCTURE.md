## 🔄 Weekly Review Process

### Every Monday Morning (30 minutes)
1. Review last week's progress
2. Update project statuses
3. Update metrics dashboard
4. Set this week's priorities
5. Log blockers and decisions

### Template: Weekly Review
```markdown
# Week of [Date]

## Completed
- [x] Task 1
- [x] Task 2

## In Progress
- [ ] Task 3 (80% done)
```

## 📱 GitHub Features to Use

### 1. GitHub Projects (Kanban Board)
- Create board for each product
- Columns: Backlog, Research, Development, Testing, Done
- Track all tasks visually

### 2. GitHub Issues
- Create issue templates for:
  - Customer interviews
  - Feature requests
  - Bug reports
  - Marketing campaigns

### 3. GitHub Discussions
- Use for brainstorming
- Community Q&A
- Decision logs

### 4. GitHub Wiki (Optional)
- Longer-form documentation
- Process guides
- Onboarding materials

### 5. GitHub Actions
- Auto-update metrics from external APIs
- Weekly automated summary reports
- Sync data from other tools

## 🎯 Success Criteria for Tracking Repo

Your tracking repo is successful when:

✅ You reference it daily for decision-making
✅ All metrics are up-to-date (weekly minimum)
✅ It accurately reflects your business status
✅ It helps you stay focused on priorities
✅ Others can understand your business from it
✅ It reduces decision fatigue and uncertainty
